# Расписание

Android-приложение для расписания колледжа: импортирует PDF из aSc TimeTables и показывает пары по дням и неделям. Работает полностью офлайн.

## Возможности

- Импорт PDF: расписание групп и расписание преподавателей (aSc), формат определяется автоматически.
- Импорт «Изменений в расписании» на конкретный день: замена преподавателя, кабинета, предмета.
- Неделя / день, подсветка текущей пары, приглушение прошедших.
- Расписание звонков по дням: Пн, Вт–Пт, Сб.
- Напоминания за 15 минут до пары.
- Виджет «Сегодня» на рабочий стол.
- Заметки и задания к парам с отметкой выполнения.
- Поиск по предмету, группе, кабинету, преподавателю.
- Тёмная тема, Material You (Android 12+).
- Экспорт недели в календарь (.ics), резервная копия в JSON.

В манифесте нет разрешения `INTERNET` — приложение не выходит в сеть.

## Сборка

Требуется JDK 17+ и Android SDK (compileSdk 37).

```bash
./gradlew assembleDebug     # отладочная сборка
./gradlew assembleRelease   # подписанная сборка
```

Для release-сборки создайте в корне `keystore.properties`:

```properties
storeFile=/путь/к/keystore.jks
storePassword=***
keyAlias=***
keyPassword=***
```

Без этого файла release-сборка соберётся неподписанной.

## Структура

```
app/src/main/java/ru/roman/schedule/
  data/          — SQLite, модели, звонки, резервные копии
  pdf/           — разбор PDF (aSc, сетка таблицы)
  ui/            — Compose-интерфейс
  widget/        — виджет на рабочий стол
  notifications/ — напоминания
```
